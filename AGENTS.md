# Ibn Hayan Repository Engineering Standards

The authoritative repository engineering and safety
instructions are maintained in:

ENGINEERING_STANDARDS.md

Read that document in full before making changes
to the repository.

The current requirements in ENGINEERING_STANDARDS.md
govern future development and Git operations.

invariants refer to the corresponding requirements in
ENGINEERING_STANDARDS.md.

of project continuity and recovery information.
